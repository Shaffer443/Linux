Sim, **é totalmente possível** criar um usuário em um servidor Linux que tenha acesso via **SSH** e que também possua **privilégios de administrador** (root).

No entanto, por questões de **segurança**, a prática mais recomendada não é dar diretamente a senha de `root` para o novo usuário. A forma padrão e mais segura é criar um usuário normal e depois conceder a ele a capacidade de executar comandos administrativos usando o comando **`sudo`**.

Aqui está um resumo dos passos mais comuns para fazer isso:

### 1. Criar o Novo Usuário

Use o comando `useradd` (ou `adduser` em alguns sistemas) para criar o usuário e, em seguida, defina uma senha forte.

Bash
    # Cria o usuário. Substitua 'novo_admin' pelo nome desejado.
    sudo useradd -m -s /bin/bash novo_admin
    # Define a senha para o novo usuário
    sudo passwd novo_admin

### 2. Conceder Privilégios de Administrador (sudo)

Para que este novo usuário possa executar comandos de administrador, você precisa adicioná-lo ao grupo correto que tem permissão para usar o `sudo`. Este grupo pode ser chamado de `sudo`, `wheel`, ou `adm`, dependendo da distribuição Linux que você está usando (ex: Ubuntu usa `sudo`, RedHat/CentOS usam `wheel`).

#### No Debian/Ubuntu:

Bash
    # Adiciona o usuário ao grupo 'sudo'
    sudo usermod -aG sudo novo_admin

#### No Red Hat/CentOS/Fedora:

Bash
    # Adiciona o usuário ao grupo 'wheel'
    sudo usermod -aG wheel novo_admin

_(Se o grupo 'wheel' ainda não estiver configurado para `sudo`, você pode precisar editar o arquivo `/etc/sudoers` usando o comando `visudo` para descomentar a linha que permite o acesso ao grupo `%wheel`.)_

### 3. Acessar via SSH

O novo usuário já deve ser capaz de fazer login via SSH, desde que o serviço SSH (`sshd`) esteja em execução no servidor.

Bash
    # De sua máquina local
    ssh novo_admin@endereco_do_seu_servidor

* * *

### **Ponto de Segurança Importante**

Uma vez logado, o usuário **`novo_admin`** pode executar comandos administrativos prefixando-os com `sudo`. Por exemplo, para instalar um pacote, ele faria:

Bash
    sudo apt update
    sudo apt install nome_do_pacote

Essa é a maneira mais segura, pois registra todos os comandos de administrador executados pelo usuário (`novo_admin`) nos logs do sistema, o que é fundamental para auditoria e segurança.
